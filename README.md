# 📚 htivo.me - Система управления библиотекой

Веб-приложение для управления библиотекой, разработанное в рамках учебной практики УП.01.

## 🚀 Инструкция по запуску

**Внимание:** перед первым запуском обязательно установите библиотеки.

1. Установите зависимости:

```bash
npm install

2. Сгенерируйте клиент Prisma:

```bash
npx prisma generate


npx prisma migrate dev

npx tsx prisma/seed.ts

npm run dev


**4. Нажми зеленую кнопку "Commit changes..."**

После этого обнови страницу. У тебя должно появиться **пять серых плашек** (одна для `npm install`, и еще 4 для остальных команд). 

Если GitHub опять съест текст, значит, браузер блокирует вставку. Тогда попробуй **вставить по одной команде** (вставить первую, нажать Commit, потом открыть заново и вставить следующую). Это займет 5 минут, но результат будет точный. Напиши, что вышло после того, как вставишь этот блок вручную.
